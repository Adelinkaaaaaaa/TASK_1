# День 1. Git

## Q0. Установка и настройка Git

Привет! Сегодня ты познакомишься с **Git** — инструментом, которым каждый день пользуется любой программист.

Каждое задание спрятано в **отдельной ветке** этого репозитория. Но сначала нужно подготовиться — установить Git и настроить его. Этим и займёмся.

---

### Что такое Git и GitHub — за одну минуту

- **Git** — программа, которая запоминает историю изменений в папке с файлами. Похоже на сохранения в игре: в любой момент можно посмотреть, что было раньше, и вернуться назад.
- **Репозиторий** — папка, за которой следит Git, вместе со всей её историей.
- **Коммит** — одно «сохранение»: снимок файлов плюс подпись, кто и зачем его сделал.
- **Ветка** — параллельная линия истории. В одной ветке можно делать одно, в другой — другое, и они друг другу не мешают. Сегодня каждое задание — это отдельная ветка.
- **GitHub** — сайт, где репозитории хранятся в интернете. Git — программа на твоём компьютере, GitHub — «облако» для твоих репозиториев.

Сейчас ты читаешь ветку `main` — это вход в наш квест.

### Шаг 1. Установи Git


1. Открой страницу https://git-scm.com/install и выбери свою систему. Мы выберем Windows.
2. Скачай **Git for Windows/x64 Setup**.
3. Запусти установщик. Почти во всех окнах просто жми **Next**, но в двух окнах нужно выбрать другое:

| Заголовок окна установщика | Что выбрать |
|---|---|
| Choosing the default editor used by Git | **Use Notepad as Git's default editor** (Блокнот) |
| Adjusting the name of the initial branch in new repositories | **Override the default branch name for new repositories** и впиши `main` |
| Все остальные окна | Ничего не меняй, жми **Next** |

4. В конце нажми **Install**, а потом **Finish**.

> ⚠️ **Почему так важно поменять редактор.** По умолчанию Git открывает редактор Vim, из которого новички не могут выйти — это настоящий мем среди программистов. Блокнот гораздо проще.

### Шаг 2. Открой терминал Git Bash

**Терминал** — это окно, в котором компьютером управляют текстовыми командами вместо мышки.

Нажми **Пуск**, набери `Git Bash` и открой его. Появится окно примерно такого вида:

```
ivan@SCHOOL-PC MINGW64 ~
$
```

- `$` — значит, компьютер ждёт твою команду.
- `~` — ты сейчас в своей домашней папке.

Главные правила терминала:

| Что нужно сделать | Как |
|---|---|
| Выполнить команду | Набрать её и нажать **Enter** |
| Вставить текст | **Shift + Insert** или правая кнопка мыши → **Paste** |
| Скопировать текст из терминала | Просто выдели его мышкой — он скопируется сам |
| Повторить прошлую команду | Стрелка **↑** |
| Дописать имя файла или папки | Начни печатать и нажми **Tab** |
| Остановить зависшую команду | **Ctrl + C** |
| Очистить экран | Команда `clear` |

> ⚠️ **Ctrl + C в терминале — это не «копировать», а «остановить».** А Ctrl + V может не сработать. Используй Shift + Insert.

### Шаг 4. Минимум команд терминала

Сегодня тебе понадобятся вот эти команды. Запомни или сохрани их:

| Команда | Что делает |
|---|---|
| `pwd` | Показывает, в какой папке ты сейчас находишься |
| `ls` | Показывает, что лежит в папке |
| `ls -a` | То же, но вместе со скрытыми файлами (их имена начинаются с точки) |
| `cd имя_папки` | Заходит в папку |
| `cd ..` | Выходит из папки на уровень выше |
| `cd ~` | Возвращает в домашнюю папку |
| `mkdir имя_папки` | Создаёт новую папку |
| `cat имя_файла` | Показывает содержимое файла |
| `explorer .` | Открывает текущую папку в Проводнике (точка — это «текущая папка») |

Теперь попробуй сам. Пользуясь только таблицей выше:

1. Перейди в домашнюю папку и посмотри, где ты находишься и что в ней лежит.
2. Создай в домашней папке папку `projects` — в ней мы будем работать весь день.
3. Зайди в `projects` и убедись, что ты действительно в ней.
4. Открой её в Проводнике.

Если всё получилось, откроется пустая папка `projects`. Её можно закрыть — дальше работаем в терминале.

### Шаг 5. Представься Git'у

Git подписывает каждый коммит твоим именем и почтой. Выполни две команды, подставив **свои** данные:

```bash
git config --global user.name "Твое имя"
git config --global user.email "ivan.petrov@example.com"
```

- **Твое имя** — как тебя называть? Это может быть твоим ником, или ФИО. Для нашего задания лучше укажи своё ФИО или username в Telegram.
- **Почта** — та же, что в твоём аккаунте GitHub. Посмотреть её можно здесь: https://github.com/settings/emails. Тогда на GitHub рядом с твоими коммитами будет твоя аватарка.
- **Кавычки обязательны.**
- `--global` означает «для всех репозиториев на этом компьютере» — настраивать придётся только один раз.

---

### Шаг 6. Ещё две настройки

```bash
git config --global init.defaultBranch main
git config --global core.editor notepad
```

- Первая — главная ветка в новых репозиториях будет называться `main`.
- Вторая — когда Git захочет, чтобы ты написал текст, он откроет Блокнот.

Если в установщике ты всё выбрал правильно, эти настройки уже стоят. Повторить их не страшно.

---

### Шаг 7. Проверь себя

```bash
git config --global --list
```

Среди строк ответа должны быть такие (с твоими данными):

```
user.name=Иван Петров
user.email=ivan.petrov@example.com
init.defaultbranch=main
core.editor=notepad
```

Если строк больше — это нормально.

**Чек-лист перед стартом:**

- [ ] `git --version` показывает версию Git
- [ ] имя и почта настроены, почта совпадает с GitHub
- [ ] есть папка `projects`
- [ ] я могу войти в свой аккаунт на https://github.com в браузере

### Если что-то пошло не так

<details>
<summary><code>bash: git: command not found</code></summary>

Закрой Git Bash и открой его заново. Если не помогло — запусти установщик ещё раз и в окне **Adjusting your PATH environment** выбери вариант с пометкой **(Recommended)**.
</details>

<details>
<summary>Опечатался в имени или почте</summary>

Просто выполни ту же команду ещё раз с правильными данными — новое значение заменит старое.
</details>

<details>
<summary>Открылся непонятный редактор, ничего не нажимается (это Vim)</summary>

Нажми **Esc**, напечатай `:q!` и нажми **Enter**. После этого выполни:

```bash
git config --global core.editor notepad
```
</details>

<details>
<summary>Команда зависла, курсор мигает, ничего не происходит</summary>

Возможно, Git открыл Блокнот и ждёт, пока ты его закроешь. Поищи окно Блокнота на панели задач, сохрани файл и закрой окно.
</details>

## Первое задание

Все задания лежат в этом репозитории на GitHub. Каждое задание — отдельная ветка: `q1`, `q2`, `q3`…

Но это репозиторий организаторов, и отправлять в него свою работу ты не сможешь. Поэтому сначала сделаем **свою копию** репозитория на GitHub. Такая копия называется **форк** (fork). После каждого задания ты будешь отправлять в неё свою работу, а проверяющие — смотреть, как ты продвигаешься.

### 1. Сделай форк

1. Войди в свой аккаунт на GitHub и открой репозиторий заданий: https://github.com/NotAXaliks/TASK_1
2. Справа вверху нажми кнопку **Fork**.
3. На странице **Create a new fork**:
   - **Owner** — твой аккаунт;
   - **Repository name** — оставь как есть: `TASK_1`;
   - ⚠️ **Сними галочку «Copy the `main` branch only»**. Иначе в твою копию не попадут ветки с заданиями!
4. Нажми **Create fork**.

Через пару секунд откроется страница `https://github.com/ТВОЙ_НИК/TASK_1` — это твоя копия. Под её названием будет написано `forked from NotAXaliks/TASK_1`.

### 2. Скачай свою копию

На странице **своей копии** нажми зелёную кнопку **Code**, выбери вкладку **HTTPS** и нажми на значок копирования справа от адреса.

Перейди в терминале в папку `projects`, которую создал в шаге 4. Теперь напечатай `git clone -b q1 ` (с пробелом в конце), вставь скопированный адрес (**Shift + Insert**) и нажми **Enter**. Должно получиться так, только с твоим ником:

```
git clone -b q1 https://github.com/ТВОЙ_НИК/TASK_1.git
```

> ⚠️ Проверь, что в адресе стоит **твой ник**, а не `NotAXaliks`. Если скачать репозиторий организаторов, отправить работу не получится.

Что делает эта команда:

- `git clone ...` — скачивает репозиторий вместе со всей его историей в новую папку `TASK_1`;
- `-b q1` — сразу переключает тебя на ветку `q1`.

Зайди в скачанную папку `TASK_1` (какой командой — ты уже знаешь) и проверь, что всё в порядке:

```bash
git status
```

`git status` — главная команда на сегодня: показывает, в какой ветке ты находишься и что изменилось.

Если `git status` ответил `On branch q1` — всё получилось, ты в первом задании! 🎉

Прочитай его описание одним из способов:

- в терминале: `cat README.md`
- на GitHub: на странице своей копии нажми на кнопку с названием ветки (сейчас там написано `main`) и выбери `q1`.

<details>
<summary><code>fatal: Remote branch q1 not found in upstream origin</code></summary>

При создании форка осталась галочка «Copy the `main` branch only», и ветки с заданиями не скопировались. Удали свою копию: на её странице открой **Settings**, пролистай в самый низ и нажми **Delete this repository**. Затем сделай форк заново — на этот раз сняв галочку.
</details>

<details>
<summary><code>fatal: destination path 'TASK_1' already exists</code></summary>

Ты уже скачивал репозиторий раньше, и папка `TASK_1` уже есть. Если ты скачал не ту копию (например, репозиторий организаторов), удали старую папку и скачай заново:

```bash
rm -rf TASK_1
```

⚠️ Эта команда удаляет папку целиком, без корзины. Используй её, только если ещё не начал выполнять задания.
</details>
